## 三、部署步骤

### 第 1 步：建 Web 函数
1. 打开 `https://console.cloud.tencent.com/scf`
2. 左侧「**函数**」→「**新建**」
3. 配置（**这几项必须对**）：
   - **函数类型**：**Web 函数**（不是事件函数！Web 函数才收 HTTP）
   - **函数名称**：`shezhang`
   - **运行环境**：`Nodejs16.13`（**必须与 scf_bootstrap 里的路径一致**，见下）
   - **启动命令**：**`./scf_bootstrap`**
4. 上传方式选「**本地上传 ZIP**」→ 传 `tencent-scf-上传.zip`
5. **提交**

### ⚠️「启动命令」和 scf_bootstrap 的关系（主公卡在这）
Web 函数不是直接调代码里的函数，而是要**先启动一个监听 `0.0.0.0:9000` 的 Web Server**。
腾讯云只认一个固定文件名 `scf_bootstrap`，「启动命令」填的就是执行它。

**官方要求**（cloud.tencent.com/document/product/583/56126）：
- 文件名**必须**叫 `scf_bootstrap`，其他名字启动不了
- shell 脚本第一行**必须**是 `#!/bin/bash`
- 启动命令**必须是绝对路径** `/var/lang/${语言}${版本}/bin/${语言}`
- Web Server **必须监听 `0.0.0.0:9000`，不能监听 `127.0.0.1`**
- 需 755/777 可执行权限

所以 ZIP 里有三个文件（**根目录，不是 scf_/ 里**）：

| 文件 | 作用 |
|---|---|
| `scf_bootstrap` | 启动脚本，内容是 `exec /var/lang/nodejs16.13/bin/nodejs server.js` |
| `server.js` | 用 Node 标准库起 HTTP Server（监听 9000），把请求转给业务 handler |
| `handler.js` | 全部业务逻辑（验签/脱敏/索引/鉴权/手机页面/黑匣子） |

> ⚠️ **运行环境版本必须与 `scf_bootstrap` 里的路径对上**。我写的是 `nodejs16.13`。
> 如果控制台只有 `Nodejs18.15` 或其他版本，告诉我，我把 bootstrap 里的路径改掉重新打包。
> （Node 运行时实际路径形如 `/var/lang/nodejs16.13/bin/nodejs`）

### 第 2 步：配环境变量
函数详情页 → 「**函数配置**」→「环境变量」→ 添加：

| 变量名 | 值 |
|---|---|
| `BOT_SECRET` | `<在此填 QQ AppSecret>` |
| `PUBKEY` | `<在此填机器人公钥>` |
| `ADMIN_TOKEN` | `<在此填推送口令>` |
| `READ_TOKEN` | `<在此填查询口令>` |

> SCF 的环境变量没有「Secret 类型」，值在控制台可见。**这里存的是 QQ AppSecret**，
> 介意的话告诉我，我可以改成每次从别处取（比如 CF Worker 转发），但那样又依赖境外服务了。

### 第 3 步：建 API 网关
1. 打开 `https://console.cloud.tencent.com/gateway`（API 网关 / Serverless HTTP）
2. 「新建服务」→ 名字 `shezhang` → 地域选**上海**或其他
3. 在服务里「**新建 API**」：
   - API 类型：**Web**
   - **请求方法**：`ANY`
   - **请求路径**：`/`
   - **后端类型**：`SCF`
   - **后端服务**：选刚才建的 `shezhang`
   - **超时**：15 秒
4. 「**发布**」服务（**必须发布，否则访问不通**）
5. 记下**默认子域名**，形如 `https://service-xxx-1234567890.ap-shanghai.apigw.tencentcs.com`

### 第 4 步：验收（按顺序）

## 六、存储说明（重要，别跳过）

当前代码的 KV 层用**内存 Map 兜底**（`scf_/index.js` 里的 `_mem`）。
云函数是**无状态的**，每次调用内存都是新的 → **重启后数据会丢**。

上线后要做两件事之一：
1. **绑 CloudBase KV**：把 `scf_/index.js` 里的 `KV()` 换成 CloudBase SDK 调用（代码里已留 `setKV()` 注入口）
2. **改用云数据库**：把索引 + 内容存 MySQL

**这一步我可以做，但要先知道主公想用哪种。** 建议走 CloudBase KV（改动最小）。
